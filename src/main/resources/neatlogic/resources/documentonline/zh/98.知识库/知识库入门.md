# 知识库入门

知识库模块用于把企业内部的操作手册、故障处理经验、常见问题、配置说明和项目资料沉淀为可检索、可审核、可持续维护的知识文档。它的核心价值是：让团队按知识圈管理知识范围，按分类组织文档，通过模板统一写作结构，并通过审核、版本和活动记录保证知识内容可靠可追溯。

## 模块定位

知识库主要围绕“知识浏览、文档沉淀、审核发布和基础配置”展开：

1. **知识分类**：按知识圈和目录组织文档，帮助用户快速浏览、定位和维护知识。
2. **知识文档**：沉淀具体知识内容，支持编辑、保存草稿、提交审核、查看版本和活动记录。
3. **知识圈**：划分不同团队、业务域或管理范围内的知识内容，并配置成员、审批人和分类目录。
4. **模板管理**：维护常用文档结构，新建文档时可直接套用固定章节。
5. **权限控制**：通过知识基础权限、知识圈成员、审批人和管理权限控制用户可见范围和操作范围。

## 核心流程

一篇知识文档从配置到发布通常按以下链路运行：

1. 管理员创建知识圈，配置审批人、成员和知识分类。
2. 管理员根据团队写作规范维护文档模板。
3. 用户进入知识分类，选择目标分类并新建文档。
4. 用户编辑正文内容，可插入图片、附件、代码块、表格、引用等内容。
5. 用户保存草稿，确认内容完整后提交审核。
6. 知识圈审批人审核文档，通过后文档成为正式版本；退回后提交人继续修改。
7. 文档发布后，用户可按分类浏览、搜索、查看版本和活动记录。

> 注意：知识圈的成员、审批人和分类调整会影响后续文档访问与维护体验。调整前建议先确认已有文档的归属关系和使用范围。

| 功能区域 | 主要作用 | 适用场景 |
|:--|:--|:--|

| [新建知识文档](新建知识文档.md) | 创建文档、编辑正文、保存草稿、提交审核和查看版本 | 需要沉淀操作手册、FAQ、故障处理方案或配置说明 |

## 入门配置顺序

首次使用知识库模块时，建议先完成最小可用配置：

1. 配置**知识基础权限**，确保用户可以进入知识库模块。
2. 创建**知识圈**，配置审批人和成员，明确哪些人可以维护和审核文档。
3. 规划**知识分类**，按业务域、知识类型、系统范围或组织范围搭建目录。
4. 维护**文档模板**，把常用章节做成模板，例如问题背景、处理步骤、影响范围、验证结果等。
5. 使用普通成员账号新建一篇测试文档，保存草稿并提交审核。
6. 使用审批人账号审核文档，验证分类、权限、版本和活动记录是否符合预期。

## 常见使用场景

### 团队沉淀操作手册

管理员先按业务域建立知识圈和分类，成员在分类下新建文档，记录系统操作步骤、配置项说明、截图和附件。文档审核通过后，团队成员可统一从知识库检索和复用。

### 故障处理经验复用

处理人可把故障现象、排查步骤、解决方案和验证结果整理成知识文档。后续遇到相似问题时，用户可通过分类、关键字或标签快速找到参考内容。

### 统一文档写作结构

管理员在模板管理中维护标准模板。用户新建文档时选择模板，系统带出固定章节，用户只需要补充具体内容，适合应急预案、巡检说明、上线记录等需要固定结构的文档。

### 多人协作维护知识

成员负责补充和更新文档内容，审批人负责审核发布。版本和活动记录会保留关键操作，便于追溯文档什么时候被修改、谁提交、谁审核以及审核结果。

## 菜单权限说明

以下权限需在“系统配置 - 权限管理”中配置。

| 菜单 | 权限 |
|:--|:--|
| 知识库 | 知识基础权限 |
| 知识圈管理 | 知识圈管理权限 |
| 模板管理 | 知识模板管理权限 |
| 飞书云文档同步管理 | 飞书云文档同步管理权限 |

知识库的数据权限还受知识圈配置影响。用户需要是对应知识圈的成员或审批人，才能查看、维护或审核该知识圈下的文档。
