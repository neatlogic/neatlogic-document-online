# 模板管理
模板用于沉淀常用的文档结构。用户在新建知识文档时，可以选择已有模板，快速生成标准化内容框架。

**相关权限**：知识模板管理权限

![](images/模板管理.png)

进入模板管理页面后，可查看已有模板列表，并进行添加、编辑、删除、启用和禁用操作。

## 添加模板
点击添加模板，可维护模板名称、模板内容和启用状态。

![](images/模板管理_添加模板.png)

模板内容适合配置固定章节，如问题背景、处理步骤、影响范围、验证结果和回滚方案等。使用模板可以减少重复编辑，提高文档格式一致性。

## 编辑模板
选择已有模板进入编辑页面，可调整模板名称、内容和状态。模板调整后，新建文档时会使用最新模板内容，已创建的文档不会自动变更。

![](images/模板管理_编辑模板.png)

## 删除模板
对不再使用的模板，可执行删除操作。删除模板不会影响已经通过该模板创建的知识文档。

![](images/模板管理_删除模板.png)

## 启用和禁用模板
模板支持启用和禁用。启用后的模板可在新建文档时选择，禁用后的模板不再提供给用户使用。

![](images/模板管理_启用和禁用模板.png)
