# 工单上报
工单上报方式主要分为单个工单上报和批量上报两种模式。

## 单个工单上报
单个工单上报提供以下两个入口：

1. 服务目录页面

![](images/服务目录.png)

2. 快捷上报入口

![](images/快捷上报.png)

### 工单提交与暂存
上报工单时，必须填写工单标题及相关必填字段，完成填写后提交工单方可通过系统校验。
![](images/工单上报.gif)
若已填写工单内容但暂无需提交，可点击“暂存”按钮将工单保存为草稿。上报人可在“[我的草稿](../工单中心/工单中心.md)”列表中查看已暂存的工单草稿，草稿支持继续编辑和提交操作。草稿提交成功后，系统将自动从草稿列表中移除对应记录。

### 工单内容说明
工单内容包含以下核心要素：标题、上报内容、描述、附件、相关知识、上报人及基本信息。

1. **标题**：即工单名称，系统不做唯一性校验，但为暂存或提交工单的必填项。
2. **上报内容**：以表单形式呈现，根据[流程设置](../流程管理/流程管理.md)中上报节点关联的表单场景动态显示。
3. **描述**：用于补充工单相关信息，其启用状态及必填校验由流程配置中上报节点的“启用描述”和“描述必填”设置控制。
    ![](images/描述配置.png)
4. **附件**：支持上传本地文件及截图，其启用状态由流程上报节点的开关配置控制。
    ![](images/附件.png)
5. **相关知识**：基于工单标题关键字智能匹配相关知识文档，点击标题可查看文档详情。数据来源为[知识库](../../98.知识库/新建知识文档.md)中所有已审批通过的文档。
   ![](images/相关知识.png)
6. **上报人**：指提交工单的用户，默认值为当前登录用户。支持修改上报人，若修改为非当前登录用户，则当前登录用户自动成为工单代报人。上报人的地域信息来源于系统配置的[地域管理](../../100.系统配置/1.用户和权限/用户和权限.md)。
7. **基本信息**：包含上报服务、优先级、标签及关注人等工单基础信息。优先级显示受[服务目录管理](../服务/服务目录管理.md)中服务配置的优先级启用和显示开关控制，表单下拉框组件支持联动修改优先级选项。标签功能目前仅用于工单标记。

## 批量上报
批量上报流程：下载模板 → 填写批量上报数据 → 导出工单
![](images/批量上报.png)
**相关权限**：需在系统配置-[权限管理](../../100.系统配置/1.用户和权限/用户和权限.md)中开启批量上报权限
