# 作业管理

自动化作业支持手动发起和定时发起两种方式。

手动发起作业的来源主要包括：[组合工具](../工具/组合工具.md)发起作业、工具测试、人工巡检、发布作业、工单[自动化节点](../../2.IT服务/流程管理/流程管理.md)触发、[自动发现](../../3.配置管理/自动发现/网段自动发现.md)触发。本文主要说明通过组合工具发起的作业。工具测试作业可参考[工具库](../工具/工具库.md)和[自定义工具库](../工具/自定义工具库.md)。

定时作业包括定时巡检、定时发布和组合工具定时作业。本文只说明组合工具相关的定时作业入口，定时巡检可参考[资产巡检](../../4.巡检/巡检管理/资产巡检.md)和[应用巡检](../../4.巡检/巡检管理/应用巡检.md)，定时发布请参考发布模块相关文档。

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要手动发起作业，阅读“手动发起作业”。
- 如果需要了解定时作业入口，阅读“定时作业”。
- 如果需要搜索、接管、撤销、执行或删除作业，阅读“作业管理-管理页”。
- 如果需要理解作业不同状态的含义，阅读“作业状态”。
- 如果需要在作业详情中执行撤销、暂停、中止、重跑或验证，阅读“作业操作”。
- 如果需要处理阶段或节点执行结果，阅读“阶段操作”。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../../100.系统配置/1.用户和权限/用户管理.md)-授权-自动化基础权限
- 包含操作：访问作业管理菜单，查看作业列表和作业详情
- 配置人员：系统超级管理员

**操作权限**
- 配置：系统配置-[用户管理](../../100.系统配置/1.用户和权限/用户管理.md)-授权-作业维护权限
- 包含操作：删除已完成作业
- 配置人员：系统超级管理员

**作业执行权限**
- 配置：[组合工具](../工具/组合工具.md)-执行权限
- 包含操作：接管状态允许接管的作业，复制作业，导出作业
- 生效条件：当前登录用户不是作业执行人，且作业状态允许接管

## 手动发起作业

组合工具发起作业有两个入口：快速发起入口和组合工具发起入口。

### 快速发起入口

自动化模块左上方提供添加作业的快捷入口。点击新增后，选择需要发起作业的组合工具，并完成作业参数、执行目标和执行账号等配置，即可发起作业。

![](images/快速发起作业.gif)

### 组合工具发起作业入口

组合工具也可以从以下位置发起作业：

- 组合工具管理页中，点击组合工具上的添加作业操作。
- 组合工具详情页中，点击添加作业操作。

![](images/组合工具发起作业.gif)

## 定时作业

定时作业通过关联组合工具和定时器，预设作业参数、执行目标、执行账号等配置。保存并激活后，系统会按照定时器规则自动发起作业。

![](images/定时作业.png)

## 作业管理

作业管理页面汇总所有途径发起的自动化作业。

### 管理页

作业管理页支持按条件搜索作业。用户可以接管除“运行中”或“已完成”之外的作业；作业执行人可以编辑作业计划时间和执行方式，也可以执行、撤销或删除作业。

- **搜索**

![](images/作业管理_搜索.png)

- **编辑计划时间和执行方式**：仅未开始执行的作业可修改。

![](images/作业管理-修改执行时间.gif)

- **撤销**：仅“已就绪”状态的作业可撤销。

![](images/作业管理-撤销.gif)

- **执行**：未开始的作业可执行。

![](images/作业管理_执行.png)

- **接管**：当作业状态不是“已验证”，且当前登录用户不是作业执行人时，可以接管作业。接管后，作业执行人会变更为当前登录用户。

![](images/作业管理_接管.png)

- **删除**：删除作业记录。

![](images/作业管理-删除.gif)

### 详情页

在作业管理页点击作业标题，可进入作业详情页面。

#### 作业状态

作业状态包括“已就绪”“待运行”“进行中”“排队中”“待输入”“暂停中”“已暂停”“中止中”“已中止”“已失败”“已撤销”“已完成”“已验证”。

**1. 已就绪**

新建作业在开始执行前，状态为“已就绪”。

作业执行人可编辑计划时间、触发方式，也可执行、删除、撤销、导出、复制和中止作业。其他有执行权限的用户可接管、删除、导出和复制作业。

![](images/作业管理_已就绪.png)

**2. 待运行**

已执行过的作业，如果所有阶段都被重置为待运行，作业状态会切换为“待运行”。

![](images/作业详情_待运行.png)

**3. 排队中**

作业开始执行后，如果执行器的并发作业数量达到上限，新分配到该执行器的作业会进入排队状态，并显示排队序号。直到作业进入执行队列后，状态才会切换为“运行中”。

如果排队作业数量也达到上限，新发起的作业会被拒绝或丢弃。

![](images/作业详情_排队中.png)

执行器的并发数量和最大等待容量由 neatlogic-runner 服务配置文件 `application.properties` 定义。文件路径为 `/app/systems/neatlogic-runner/config`，参数说明如下：

![](images/作业详情_排队中_配置文件参数.png)

作业执行人可删除、暂停、中止、导出和复制作业。其他有执行权限的用户可接管、删除、导出和复制作业。

**4. 进行中**

作业开始执行且不需要排队时，状态会切换为“运行中”。

作业执行人可删除、暂停、导出、复制和中止作业。其他有执行权限的用户可接管、删除、导出和复制作业。

![](images/作业详情_进行中.png)

**5. 待输入**

作业运行到需要输入的脚本时，阶段和作业状态会从“运行中”切换为“待输入”。

![](images/作业管理_待输入.png)

**6. 暂停中和已暂停**

“运行中”的作业点击暂停后，阶段和作业状态会先切换为“暂停中”。正在运行的节点全部执行完成后，作业状态切换为“已暂停”。

![](images/作业管理_已暂停.png)

**7. 中止中和已中止**

“运行中”的作业点击中止后，阶段和作业状态会先切换为“中止中”。正在运行的节点开始中止进程，直到所有“运行中”的节点切换为“已中止”后，阶段和作业状态切换为“已中止”。

![](images/作业管理_已中止.png)

**8. 已失败**

当作业中的阶段脚本执行失败，并且阶段策略设置为失败后停止时，阶段和作业状态会切换为“已失败”。

![](images/作业管理_已失败.png)

**9. 已撤销**

“已就绪”的作业被撤销后，作业状态切换为“已撤销”。

![](images/作业管理_已撤销.png)

**10. 已完成**

作业所有阶段都执行完成后，所有阶段状态和作业状态都会切换为“已完成”。

![](images/作业管理_已完成.png)

**11. 已验证**

对已完成作业执行验证操作后，作业状态切换为“已验证”。

![](images/作业管理_已验证.png)

#### 作业操作

在不同作业状态下，系统支持执行、撤销、暂停、中止、接管、验证和重新执行等操作。执行、撤销、暂停、中止、验证和重新执行通常由作业执行人操作。作业全过程支持查看流程图、控制台、参数、复制作业和导出作业。

- **撤销**：仅“已就绪”状态的作业可撤销。

![](images/作业管理_详情_撤销.png)

- **暂停、中止**：“运行中”的作业可暂停或中止。

![](images/作业管理_详情_进行中.png)

- **重新执行**：“已失败”“已暂停”“已中止”“已完成”状态的作业可重新执行。

![](images/作业管理_详情_重新执行.png)

- **验证**：“已完成”的作业可验证。验证后的作业彻底关闭，除删除外不能再执行其他作业操作。

![](images/作业管理_详情_验证.png)

- **接管**：当当前登录用户不是作业执行人，且作业状态不是“已验证”时，可以接管作业。接管后，作业执行人会变更为当前登录用户。

![](images/作业管理_详情_接管.png)

- **查看流程图、控制台、参数、复制作业、导出作业**

![](images/作业管理_详情_公共操作.png)

#### 阶段操作

阶段操作主要分为 runner 执行、target 执行和 SQL 执行三种情况。

**target 执行**

target 执行表示在远程节点上执行脚本。该阶段会展示执行节点列表，节点支持重置、执行和忽略等操作。

- **重置**：将节点状态重置为“待运行”。“已失败”“已忽略”和“已完成”的节点都可以重置。

![](images/作业管理_重置节点.png)

- **忽略**：将节点状态标记为“已忽略”。重新执行作业或阶段时，系统会忽略该节点。只有“已失败”的节点可以忽略。

![](images/作业管理_忽略节点.png)

- **查看节点详情**：点击节点 IP，可查看节点执行情况，包括脚本运行日志、输入参数、输出参数和运行记录。

![](images/作业管理_详情_查看节点详情.png)

**runner 执行**

runner 执行表示在本地执行器上执行脚本。该阶段支持忽略、重置和执行脚本操作，并可查看整个阶段的标准输出、输入参数、输出参数和运行记录。相关数据支持导出。

![](images/作业管理_详情_本地执行.png)

**SQL 执行**

SQL 执行表示执行 SQL 文件。执行前需要先执行导入 SQL 文件的脚本，生成 SQL 清单。

![](images/作业管理_详情_SQL执行.png)
