# 自动化入门

自动化模块用于把脚本工具、执行目标、执行账号、作业参数和执行记录组织成可复用、可追踪的自动化作业。它的核心价值是：让管理员沉淀标准工具和组合工具，让执行人按权限发起作业，让运维操作从临时脚本执行变成有目标、有参数、有日志、有结果的可管理流程。

## 模块定位

自动化主要把“能执行什么、对谁执行、如何执行、执行结果如何追踪”串成闭环：

1. **执行基础**：通过资源中心、账号、标签、视图和执行器组，准备可连接、可筛选、可调度的执行目标。
2. **工具沉淀**：通过工具库和自定义工具库管理内置工具、自定义脚本、版本、测试和审批。
3. **流程编排**：通过组合工具把工具、阶段、参数、执行方式、执行目标和并发策略编排成可复用作业模板。
4. **作业执行**：通过作业管理发起、查看、接管、暂停、中止、重新执行和验证自动化作业。
5. **服务化使用**：通过定时作业和快捷服务，把固定任务变成定期自动执行或一键发起的服务入口。

## 常见使用场景

### 管理员编排标准作业

管理员先整理执行目标、账号和基础参数，再把内置工具或自定义工具放入组合工具中，按阶段配置执行方式、参数映射、目标筛选和并发策略。审批通过后，用户即可按权限发起作业。

### 执行人手动发起作业

执行人可通过快速入口或组合工具详情发起作业，填写作业参数、选择执行目标和执行账号后保存或执行。作业运行后，可在作业管理中查看状态、控制台、节点日志、输入输出参数和执行记录。

### 定期执行固定任务

对于定时巡检、定时清理、定时同步等重复任务，可以创建定时作业，关联组合工具和定时器，并预设参数、执行目标和账号。保存后可先测试，再按计划自动运行。

### 封装常用快捷入口

如果某类作业经常由不同用户发起，且参数或执行目标比较固定，可以通过快捷服务配置目录和服务，让用户从服务目录直接发起作业，减少重复选择和填写。

### 处理远程连接和执行失败

作业失败时，通常先确认是否分配到执行器，再检查执行目标连接、账号协议、资产标签、参数映射和组合工具阶段配置。常见问题可优先参考自动化 FAQ。

## 核心流程

一个自动化作业通常围绕“模板、目标、执行、记录”形成闭环：

1. **沉淀能力**：把脚本、命令或标准操作封装成工具，并通过测试和审批形成可使用版本。
2. **编排模板**：把工具按阶段组合起来，定义参数、执行方式、执行目标、并发策略和通知规则。
3. **发起作业**：用户通过组合工具、快捷服务、定时作业或流程节点发起作业，并补充必要参数。
4. **调度执行**：系统根据执行方式、执行器组、账号协议和目标节点分发任务，按阶段记录执行过程。
5. **追踪结果**：执行人查看状态、日志、控制台、输入输出参数和节点结果，并按需要暂停、中止、接管、重跑或验证。

> 注意：组合工具、工具版本、执行目标、账号、权限等配置会影响后续新发起的作业；已生成的历史作业通常以当时的配置和执行记录为准。

## 入门配置

首次使用自动化模块时，先完成一条可跑通的最小链路即可：

1. **先通执行环境**：确认 runner、执行器组、网络策略、资产和账号可用。
2. **再定管理口径**：准备工具分类、工具目录、操作级别，以及必要的参数集。
3. **选一个简单工具**：优先用内置工具或简单自定义工具完成测试，确认参数和执行方式没问题。
4. **编一个最小组合工具**：只保留必要阶段、参数映射、执行目标和执行用户，先保证能成功发起作业。
5. **用普通账号验证**：从发起、执行、查看日志到验证结果走一遍，再补充定时作业、快捷服务、通知和 Tagent 等扩展配置。

## 功能地图

| 功能区域 | 主要作用 | 适用场景 |
|:--|:--|:--|
| [自动化配置](配置/自动化配置.md) | 维护工具分类、目录、参数集、全局参数、场景和模板 | 需要统一工具管理、参数复用和场景分类 |
| [资产清单](资源中心/资产清单.md) | 查看和管理自动化可消费的 IP 资产 | 需要选择远程执行目标或按资产信息过滤节点 |
| [账号管理](资源中心/账号管理.md) | 配置连接协议和账号 | 作业需要通过 ssh、tagent、database 等协议连接目标 |
| [标签管理](资源中心/标签管理.md) | 管理资产标签 | 需要按标签筛选测试目标或执行目标 |
| [视图设置](资源中心/视图设置.md) | 配置资产清单的数据视图和字段映射 | 需要调整资产清单树目录、字段和搜索条件 |
| [工具库](工具/工具库.md) | 查看、测试系统内置工具，并发布为组合工具 | 内置工具已满足单步或基础操作需求 |
| [自定义工具库](工具/自定义工具库.md) | 创建、审批、测试、版本管理和导入导出自定义工具 | 需要沉淀自有脚本、库文件或包 |
| [组合工具](工具/组合工具.md) | 编排阶段、工具、参数、执行目标、并发和通知 | 需要把多个操作组织成可复用的自动化流程 |
| [作业管理](作业/作业管理.md) | 管理所有自动化作业及其状态、日志和执行结果 | 需要手动发起、追踪、接管、暂停、中止或验证作业 |
| [定时作业](作业/定时作业.md) | 按定时器规则自动发起组合工具作业 | 需要定期执行巡检、清理、同步或发布类任务 |
| [快捷服务](快捷服务/快捷服务.md) | 将常用作业封装为服务入口 | 参数和执行目标较固定，希望快速发起作业 |
| [Tagent服务](Tagent服务/Tagent服务.md) | 在受管目标机上部署可替代连接协议的服务 | Windows、账号频繁变更、多账号或深度自动化场景 |
| [自动化-常见问题FAQ](常见问题解答/自动化-常见问题FAQ.md) | 汇总组合工具、执行目标和作业失败等常见问题 | 作业无法执行、组合工具无法编辑或参数映射异常 |

## 阅读建议

如果只想快速理解模块，可以先阅读本文，再阅读“组合工具”和“作业管理”。如果需要配置一条可执行的自动化流程，建议依次阅读自动化配置、资产清单、账号管理、工具库或自定义工具库、组合工具和作业管理。若重点是重复执行和自助入口，则优先阅读定时作业和快捷服务。
