# 应用巡检

应用巡检用于按应用和模块维度查看资产巡检情况，并对应用范围内的资产发起巡检。

在应用巡检页面，可以维护应用或模块信息，配置资产清单展示范围，设置纳管应用，发起应用资产批量巡检、单个资产巡检和定时巡检，也可以查看巡检报告并维护应用或资产维度的阈值规则。

每个应用模块下的最新问题和资产清单仅显示巡检状态存在异常的资产，适合从业务应用视角快速定位异常资产。

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要维护应用或模块基础信息，阅读“应用与模块管理”。
- 如果需要配置资产清单展示内容，阅读“资产清单设置”。
- 如果需要控制应用巡检页面展示哪些应用，阅读“纳管应用设置”。
- 如果需要对应用或模块下的资产发起巡检，阅读“巡检操作”。
- 如果需要周期性巡检应用资产，阅读“定时巡检”。
- 如果需要调整应用或资产的巡检判断规则，阅读“阈值规则”。
- 如果需要查看资产巡检结果详情，阅读“巡检报告”。
- 如果需要确认可执行的操作范围，阅读“权限”。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../../100.系统配置/1.用户和权限/用户管理.md)-授权-巡检基础权限、巡检管理员权限、巡检单个执行或批量执行权限、巡检定时执行权限
- 包含操作：访问应用巡检页面、设置资产清单、设置纳管应用、发起应用资产批量巡检、发起单个资产巡检、配置定时巡检、设置阈值规则和查看巡检报告
- 配置人员：系统超级管理员或巡检管理员

**关联权限**
- 应用与模块的添加、编辑和删除，需要拥有应用系统模型、应用模块模型的相应权限。
- 配置入口可参考[模型管理](../../3.配置管理/系统管理/模型管理.md)。

## 应用与模块管理

应用巡检页面支持添加、编辑和删除应用或模块。该能力用于维护应用巡检页面左侧应用模块树中的基础数据。

添加、编辑或删除应用和模块时，需要拥有应用系统模型、应用模块模型的相应权限。若没有对应模型权限，可能只能查看数据，无法执行维护操作。

### 添加

添加用于新增应用或模块信息。新增后，应用或模块会出现在应用巡检的应用模块树中，用于后续查看资产、发起巡检或配置阈值规则。

![](images/应用巡检_添加.png)

### 编辑

编辑用于修改已有应用或模块信息。选择需要编辑的应用或模块后，调整基础信息并保存即可。

![](images/应用巡检_编辑.png)

### 删除

删除用于移除不再需要的应用或模块信息。删除前应确认该应用或模块是否仍被资产、巡检配置或其他业务场景使用，避免影响后续巡检查看。

![](images/应用巡检_删除.png)

## 设置

应用巡检页面支持设置功能，包括资产清单设置和纳管应用设置。设置类操作需要巡检管理员权限。

### 资产清单设置

资产清单设置用于配置应用巡检页面中资产清单 Tab 的展示内容。

每个数据配置会在资产清单 Tab 中生成一个独立表格。通过添加多个数据配置，可以按不同视图展示应用或模块下的资产信息，满足不同场景下的资产查看需求。

![](images/应用巡检_资产清单设置.png)

#### 数据配置

每个数据配置包含以下内容：

- **资产清单**：选择模板类型为“应用清单资产详情”的自定义视图。视图需提前在[视图设置](../资源中心/视图设置.md)中创建。
- **表头属性**：选择需要在表格中显示的属性列，如 IP 地址、名称、状态、环境等。
- **属性排序**：支持对已选择的表头属性进行拖动排序，用于调整列的显示顺序。

#### 操作说明

**添加数据配置**

1. 点击“添加数据”按钮，创建新的数据配置。
2. 在资产清单下拉框中选择视图。
3. 在表头属性列表中，勾选需要显示的属性。
4. 通过拖动调整属性的显示顺序。
5. 点击保存完成配置。

**编辑数据配置**

选择需要修改的数据配置，调整资产清单或表头属性后保存。保存后，资产清单 Tab 中对应表格会按新配置展示。

**删除数据配置**

选择需要删除的数据配置，点击删除按钮并确认后保存设置。删除后，资产清单 Tab 中对应的表格将不再显示。

![](images/应用巡检_数据配置.png)

### 纳管应用设置

纳管应用设置用于控制哪些应用显示在应用巡检页面中。

该设置适合在应用数量较多时缩小展示范围，让应用巡检页面只展示当前需要关注的应用。

支持以下配置方式：

- **全部应用**：选择“全部应用”后，应用巡检会显示所有应用。
- **指定应用**：手动选择需要纳管的应用，仅选中的应用会在应用巡检中显示。
- **清空选择**：未选择任何应用时，应用清单为空。

![](images/应用巡检_纳管应用设置.png)

**操作步骤**

1. 点击页面左上方的“设置”按钮，打开设置对话框。
2. 在“纳管应用”标签页中，选择需要纳管的应用。
3. 点击确认保存设置，应用巡检页面会根据配置显示对应应用列表。

## 巡检操作

巡检操作用于对应用或模块下的资产发起即时巡检。

选择需要执行巡检的应用或模块后，点击巡检按钮，选择需要巡检的模块及环境并确认，即可对包含的资产对象发起巡检。该操作需要巡检单个执行或批量执行权限。

发起巡检前，建议先确认应用或模块下的资产已正确纳入资产清单，并且资产所属模型已在[巡检定义](巡检定义.md)中关联巡检工具。

### 应用资产批量巡检

应用资产批量巡检用于对应用范围内的多台资产发起巡检。

选择应用后，点击巡检按钮，再选择需要巡检的环境和所属模块。确认后，系统会对符合条件的资产发起巡检作业。

![](images/应用巡检_巡检.png)

### 单个资产巡检

单个资产巡检用于临时检查应用或模块下的某一台资产。

选择目标应用或模块，进入资产清单，找到目标资产后点击资产上的巡检按钮，确认后即可执行巡检。

![](images/应用巡检_单个资产巡检.png)

## 定时巡检

定时巡检用于周期性巡检应用中的资产。该操作需要巡检定时执行权限。

配置定时巡检后，系统会按计划对应用范围内符合条件的资产生成巡检作业。巡检结果可在应用巡检、巡检作业和最新问题中查看。

![](images/应用巡检_定时巡检.gif)

## 阈值规则

阈值规则用于定义巡检指标的判断条件。应用巡检页面支持设置应用阈值规则，也支持从资产入口设置全局或应用阈值规则。

执行应用巡检时，资产会优先使用当前应用的阈值规则；未命中应用阈值规则时，再按全局阈值规则判断。

### 应用阈值规则

应用阈值规则用于直接设置应用层的指标判断规则。

选择应用后，点击右上方的阈值规则按钮，即可设置该应用的阈值规则。配置完成后，应用范围内的资产巡检会优先按应用阈值规则判断结果。

![](images/应用巡检_应用阈值规则.gif)

### 资产阈值规则

资产阈值规则用于从资产维度设置全局阈值规则或所在应用的阈值规则。

当同一资产同时存在全局规则和应用规则时，执行应用巡检会优先遵循当前应用的阈值规则。

![](images/应用巡检_资产阈值规则.gif)

## 巡检报告

点击资产 IP 可以查看该资产的巡检报告。

巡检报告展示资产各项指标的判断结果，支持导出和查看历史报告。该页面适合用于分析具体异常指标、对比历史巡检情况，以及留存巡检结果。

![](images/应用巡检_查看巡检报告.gif)
