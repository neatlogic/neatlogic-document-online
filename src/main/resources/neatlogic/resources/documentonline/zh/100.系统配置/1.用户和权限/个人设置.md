# 个人设置

个人设置用于维护当前登录用户自己的基础信息、登录安全、页面偏好和任务授权。

当用户需要修改联系方式、更新密码、调整登录后的默认入口，或临时把待处理工单授权给他人处理时，可以进入个人设置完成配置。

入口：点击用户头像-个人设置。

![](images/个人设置.png)

## 阅读路径

- 如果只是查看自己的账号信息，先阅读“基本信息”。
- 如果需要调整登录安全，阅读“修改密码”。
- 如果需要控制弹窗提醒、默认模块或默认首页，阅读“个性化”。
- 如果临时无法处理工单，阅读“任务授权”。

## 基本信息

基本信息用于查看当前用户的身份、组织、角色和权限来源。

基本信息中可以修改当前用户的用户名、电话和邮箱，也可以查看分组、分组角色、角色、权限、令牌和服务器 ID 等数据。

- **分组**：用户关联的分组。
- **分组角色**：用户所属分组关联的角色。
- **角色**：包括用户直接关联的角色，以及通过分组继承的角色。
- **权限**：当前用户拥有的所有权限。
- **服务器 ID**：对应服务节点状态管理页的 ID 字段。

![](images/个人设置-基本信息.png)

## 修改密码

修改密码用于当前用户自行更新登录密码。

当用户怀疑密码泄露，或需要按安全要求定期更换密码时，可以在这里完成密码修改。

![](images/个人设置-修改密码.png)

## 个性化

个性化用于调整当前用户自己的页面交互和默认入口。

个性化中可以设置弹窗提醒、默认模块和模块默认首页。这里的设置只影响当前用户。

### 弹窗提醒

弹窗提醒用于控制操作成功后是否需要用户手动确认下一步。

平台有四个功能支持弹窗提醒，分别是创建用户、创建角色、创建分组和工单上报。

![](images/个人设置-个性化_弹窗提醒设置.png)

弹窗提醒配置有两个状态：禁用和激活。默认选项为单选。

1. 激活
   
   激活状态下，每次执行操作成功后，都会出现弹窗，没有默认选项，需要用户手动操作才能关闭弹窗。
   ![](images/个人设置-个性化_弹窗提醒.png)
2. 禁用
   
   禁用状态下，每次执行操作成功后，按照默认选项配置自动跳转页面。

### 默认模块

默认模块用于控制用户登录系统后首先进入哪个模块。

引用全局配置时，按照[默认首页](../5.基础服务/默认首页.md)的配置生效。

只有已激活且授权给当前用户的配置有效，当用户匹配到多个配置时，会执行排序最靠前的配置。

![](images/个人设置-个性化_默认模块引用全局.png)

未引用全局，支持用户自定义默认模块，默认模块单选但非必填。

![](images/个人设置-个性化_默认模块设置.png)

未设置默认模块，登录成功后，默认跳转到欢迎页面。

![](images/个人设置-个性化_无默认模块.png)

**备注**：用户可选模块只显示有访问权限的模块，与上方模块菜单保持一致。

### 默认首页

默认首页用于控制用户进入某个模块后默认打开哪个页面。

每个模块都可以设置默认首页，默认首页单选但非必填。

![](images/个人设置-个性化_默认首页设置.png)

**备注**：用户可设置默认首页的模块只包括有访问权限的模块，与上方模块菜单一致。

## 任务授权

任务授权用于把当前用户的待处理工单授权给指定用户代为处理。

当用户出差、休假或临时无法处理工单时，可以提前配置任务授权，避免工单长时间无人处理。

处理人任务授权只应用于工单中，所以用户必须有 IT 服务基础权限才能配置任务授权。

任务授权的配置包括激活状态、起止时间、授权用户和授权服务。

![](images/个人设置-个性化_任务授权设置.png)

**备注**：授权维度是工单所属服务，不能具体到某一张工单。
