# 数据库变更记录

数据库变更记录用于查看当前租户的 SQL 执行记录。

记录内容包括版本、模块、执行状态、SQL 语句、错误信息和执行时间等信息。该页面适合用于确认升级脚本、初始化脚本或数据库变更是否执行成功。

![](images/数据库变更记录.png)

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要确认数据库变更是否执行成功，阅读“查看变更记录”。
- 如果需要排查 SQL 执行失败原因，阅读“查看详情”。
- 如果需要复制 SQL 语句或错误信息，阅读“查看详情”。
- 如果需要确认可执行的操作范围，阅读“权限”。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../1.用户和权限/用户管理.md)-授权-系统核心基础权限
- 包含操作：访问数据库变更记录页面、查看 SQL 语句、查看错误信息和复制详情
- 配置人员：系统超级管理员

## 查看变更记录

数据库变更记录会展示当前租户下的 SQL 执行情况。

通过版本、模块、执行状态和执行时间，可以确认某次升级或配置初始化涉及的 SQL 是否已经执行，以及执行结果是否正常。

## 查看详情

SQL 语句和错误信息支持查看详情。

将光标聚焦到对应图标时，页面会展示详细信息。详情内容支持一键复制，便于在排查数据库变更失败、升级异常或脚本执行问题时使用。
