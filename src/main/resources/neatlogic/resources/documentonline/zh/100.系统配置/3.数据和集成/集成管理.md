# 集成管理

集成管理用于配置系统与外部服务之间的接口调用。当流程动作、节点动作、自动化发布或其他业务场景需要调用外部接口时，可以先在集成管理中维护接口配置，再在具体场景中引用和执行。

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要定义接口入参和出参结构，阅读“数据规范”。
- 如果需要配置接口地址、认证和参数，阅读“请求设置”“认证方式”和“参数说明”。
- 如果系统字段和外部接口字段不一致，阅读“输入转换与输出转换”。
- 如果需要验证接口是否可用，阅读“接口测试”。
- 如果需要排查调用失败或返回异常，阅读“调用记录”。
- 如果需要控制哪些对象可以执行集成，阅读“权限配置”。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../1.用户和权限/用户管理.md)-授权-集成管理权限
- 包含操作：新增、编辑、删除和维护集成配置
- 配置人员：系统超级管理员

**执行权限**
- 配置：集成管理-权限配置-执行权限
- 包含操作：在被授权的业务场景中执行对应集成配置
- 配置人员：有集成管理权限的用户

## 数据规范

集成配置提供**自定义**、**矩阵数据规范**、**表单外部数据源查询**和**发布触发器数据规范**四种数据规范类型，集成配置的数据规范类型决定使用范围。

数据规范用于定义集成配置的输入、输出结构，帮助配置人员明确接口需要哪些参数、会返回哪些数据。选择不同的数据规范后，请求设置中的输入转换或输出转换区域会显示对应的配置提示.

![集成管理_数据规范](images/集成管理_数据规范.png)

### 自定义数据规范

自定义数据规范适合手工定义接口字段。当接口字段由外部系统提供，或系统中没有可直接复用的数据结构时，可以根据外部接口要求维护字段名称、类型、是否必填和说明。

自定义数据规范常用于[流程](../../2.IT服务/流程管理/流程管理.md/#3-流程设置)或节点动作设置，也适用于自动处理节点需要调用外部接口的场景。

![集成管理_流程动作设置](images/集成管理_流程动作设置.gif)

![集成管理_节点动作设置](images/集成管理_节点动作设置.png)

### 矩阵数据规范

矩阵数据规范适合外部数据源矩阵场景。使用该规范时，需要按照系统规定的输入和输出格式编写转换脚本，避免接口返回结构与矩阵要求不一致。

![集成管理_矩阵](images/集成管理_矩阵.png)

**输入规范格式：**

```json
{
  "keyword": "字符串",
  "defaultValue": "json数组",
  "currentPage": "整形",
  "pageSize": "整形",
  "needPage": "布尔型",
  "sourceColumnList": [
    {
      "column": "字符串",
      "expression": "字符串",
      "value": "字符串"
    }
  ]
}
```

**输出规范格式：**

```json
{
  "currentPage": 0,
  "pageSize": 0,
  "pageCount": 0,
  "rowNum": 0,
  "tbodyList": [],
  "theadList": [
    {
      "title": "字符串",
      "key": "字符串",
      "type": "input",
      "isSearchable": 1,
      "isSearch": 1,
      "primaryKey": 0,
      "isMobile": false,
      "isPC": false
    }
  ]
}
```

### 发布触发器数据规范

发布触发器数据规范适合集成预发布模块的 Webhook 配置。当外部系统需要接收发布触发数据时，可以通过该规范统一触发数据结构；如果实际输入参数与系统规定的输入规范不一致，需要通过输入转换进行适配。

![集成管理_自动发布webhook](images/集成管理_自动发布webhook.png)

**输入规范格式：**

```json
{
  "appSystemId": "长整数",
  "appSystemName": "字符串",
  "appSystemAbbrName": "字符串",
  "appModuleId": "长整数",
  "appModuleName": "字符串",
  "appModuleAbbrName": "字符串",
  "envName": "字符串",
  "buildNo": "整形",
  "scenarioName": "字符串",
  "targetEnvName": "字符串"
}
```

## 请求设置

请求设置用于维护接口地址、请求方式、请求头、认证方式、请求参数等信息。

配置请求设置前，应先确认外部接口文档中的请求方式、认证要求和参数格式，再按接口要求逐项填写。请求设置完成后，建议立即进行接口测试，确认接口能够正常连通并返回预期结果。

## 认证方式

认证方式用于配置调用外部接口时的身份校验信息。当外部接口需要账号、令牌或其他认证信息时，可以在这里维护认证配置；配置完成后，系统会在调用接口时按规则携带对应的认证信息。

集成配置支持四种认证方式，可根据目标接口要求选择：

- **无需认证**：接口不要求身份验证。
- **内部认证**：仅用于访问系统内部接口。
- **Basic 认证**：使用标准 HTTP Basic 认证。
- **Bearer Token 认证**：使用基于 Token 的认证方式。

![集成管理_认证类型](images/集成管理_认证类型.gif)

**注意：** 仅当访问系统内部接口时，才可使用“内部认证”方式。

## 参数说明

参数说明用于定义接口的**输入参数**和**输出参数**。有些集成配置在业务场景中执行时，需要由引用方传入输入参数值；接口执行完成后，引用方也可能需要使用输出参数的值继续处理后续逻辑。

配置人员可以在参数说明中维护参数名称、类型、是否必填和说明，让引用方知道需要传入哪些值，以及接口会返回哪些可使用的结果。

只有数据规范为**自定义**时，配置人员才可以在参数说明中自由定义输入参数和输出参数。其他数据规范的输入输出格式由系统固定，不支持在这里自定义。

![集成管理_参数说明](images/集成管理_参数说明.png)

## 输入转换与输出转换

输入转换用于把系统内的数据转换成外部接口需要的请求格式，输出转换用于把接口返回结果转换为系统后续可使用的数据结构。当系统字段与外部接口字段不一致时，可以通过转换规则完成映射，避免在每个引用场景中重复处理字段差异。

![集成管理_输入参数转换](images/集成管理_输入参数转换.png)

![集成管理_输出参数转换](images/集成管理_输出参数转换.png)

## 接口测试

接口测试用于在保存或发布前验证配置是否可用。配置完成后，可以在测试功能中输入测试参数，向目标接口发起真实调用并查看返回结果；测试失败时，可以根据返回信息检查请求地址、认证信息、参数格式、转换逻辑和网络连通性，测试成功后再到流程、自动化或其他业务场景中引用该集成配置。

![集成管理_测试](images/集成管理_测试.gif)

## 调用记录

调用记录用于查看接口执行历史。当接口执行失败、返回异常，或业务场景没有得到预期结果时，可以优先查看调用记录，并根据其中的请求来源、发起时间、执行状态、输入参数、返回结果和异常信息定位问题。

![集成管理_调用记录](images/集成管理_调用记录.png)

调用记录支持查看单次调用详情，也支持按用户、执行状态、发起时间范围和输入参数内容进行过滤。

![集成管理_过滤调用记录](images/集成管理_过滤调用记录.png)

## 权限配置

权限配置用于控制谁可以维护集成配置，以及谁可以执行指定集成。菜单权限决定用户是否可以进入集成管理页面维护配置；执行权限决定哪些用户或业务场景可以调用该集成配置。

![集成管理_菜单权限](images/集成管理_菜单权限.png)

只有菜单权限并不代表可以执行所有集成配置。若要在流程动作等业务场景中成功调用某个集成配置，还需要被授予该集成配置的**执行权限**；否则，调用会失败。

![集成管理_执行权限](images/集成管理_执行权限.png)
