# 矩阵管理

矩阵管理用于维护可被表单、流程、自动化工具参数、组合工具作业参数等业务配置引用的结构化数据。当业务场景需要从一组稳定数据中选择、过滤或映射字段时，可以先在矩阵管理中整理数据，再由具体功能引用。

矩阵按来源和用途分为六类：**私有数据源**、**自定义数据源**、**外部数据源**、**数据库视图**、**配置项**和**自定义视图**。不同类型的矩阵适用于不同数据来源，配置前建议先确认数据由系统提供、人工维护、外部接口返回，还是来自配置管理视图。

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要引用系统已有用户、角色或分组数据，阅读“私有数据源”。
- 如果需要维护业务字典、分类或枚举值，阅读“自定义数据源”。
- 如果需要通过外部接口获取矩阵数据，阅读“外部数据源”。
- 如果需要引用本地数据库视图结果，阅读“数据库视图”。
- 如果需要在业务中选择配置项对象，阅读“配置项”。
- 如果需要引用配置管理中的公共视图，阅读“自定义视图”。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../1.用户和权限/用户管理.md)-授权-矩阵管理权限
- 包含操作：新增、编辑、删除、导入、导出和维护矩阵
- 配置人员：系统超级管理员

## 私有数据源

私有数据源是系统出厂预置的数据源类型，用于把系统内部高频使用的基础数据固化为矩阵。私有数据源矩阵不支持修改，常见数据包括标签（执行器组标签）、执行器组、角色、用户、分组、优先级（工单）、流程状态和流程步骤状态等。

当业务配置中需要直接引用系统基础数据时，可以使用私有数据源矩阵。矩阵内容会跟随系统基础数据变化而变化，不需要配置人员手工维护。

![矩阵管理_私有数据源矩阵](images/矩阵管理_私有数据源矩阵.png)

角色矩阵适合用于按角色选择、过滤或授权的场景。

![矩阵管理_私有数据源矩阵_角色](images/矩阵管理_私有数据源矩阵_角色.png)

## 自定义数据源

自定义数据源适合维护业务字典、分类、枚举值等由配置人员管理的数据。它的灵活性较高，矩阵属性可以按业务需要自行配置，数据可以手工新增，也可以通过导入导出批量维护。

**操作步骤**：添加矩阵 -> 配置属性 -> 添加行（数据）。

![矩阵管理_添加](images/矩阵管理_添加.gif)

自定义数据源的属性类型支持文本框、日期、下拉框、用户、分组、角色、地域和模型。其中，用户、分组、角色、地域和模型的数据来自系统内对应的管理页面。

相关功能可参考：

- [用户管理](../1.用户和权限/用户管理.md)
- [分组管理](../1.用户和权限/分组管理.md)
- [角色管理](../1.用户和权限/角色管理.md)
- [地域管理](../1.用户和权限/地域管理.md)
- [模型管理](../../3.配置管理/系统管理/模型管理.md)

**注意：** 添加数据时，如果某个属性选择了多个值，系统会根据笛卡尔积规则自动生成多条数据。

自定义数据源支持导入导出，适合批量维护或迁移矩阵配置。

![矩阵管理_导入导出](images/矩阵管理_导入导出.png)

- **导出数据**：将当前自定义数据源矩阵的所有数据导出为 Excel 文件。
- **导出模板**：导出用于导入数据的 Excel 模板。
- **导入数据**：将 Excel 文件中的数据导入当前矩阵。
- **导出矩阵**：将整个矩阵导出为 `bak` 格式的备份文件。

导入数据时，不同属性类型支持的识别方式不同：用户和角色支持通过 uuid、id 和名称导入；分组支持通过 uuid、名称和全路径导入；地域支持通过 uuid 和名称导入。

## 外部数据源

外部数据源通过关联[集成管理](../../100.系统配置/3.数据和集成/集成管理.md)中的集成配置获取数据。当矩阵数据来自外部接口，且不希望在系统中重复维护时，可以使用外部数据源矩阵。

矩阵引用的集成配置必须按矩阵数据规范完成输入和输出转换，系统才能根据接口返回结果生成有效矩阵数据。

![矩阵管理_外部数据源矩阵](images/矩阵管理_外部数据源矩阵.png)

添加外部数据源矩阵后，系统会进入矩阵编辑页面，并允许更换关联的集成配置。需要注意的是，如果矩阵已经被其他功能引用，则无法更换集成配置。

![矩阵管理_外部数据源矩阵_编辑](images/矩阵管理_外部数据源矩阵_编辑.png)

## 数据库视图

数据库视图矩阵通过导入 SQL 配置文件，查询本地数据库中的数据并生成矩阵数据。它适合已经通过 SQL 整理好查询结果，并希望把结果作为可选数据使用的场景。

使用前应确认视图字段稳定，避免后续引用场景因字段变化受到影响。

![矩阵管理_数据库视图矩阵](images/矩阵管理_数据库视图矩阵.png)

**配置文件示例：**

```xml
<view>
   <!--视图字段定义，需要SQL语句返回对应列-->
  <attrs>
    <attr name="user_id" label="用户ID" />
    <attr name="user_name" label="用户名" />
    <attr name="teamName" label="分组" />
  </attrs>
  <sql>
    SELECT
    <!--必须包含id字段-->
    `u`.`id` AS id,
    <!--必须包含uuid字段-->
    `u`.`uuid` AS uuid,
    <!--下列字段需要在上面attrs中定义才生效-->
    `u`.`user_name` AS name,
    `u`.`user_id` as user_id,
    `u`.`user_name` as user_name,
    group_concat( `t`.`name`) AS teamName
    FROM `user` `u`
    LEFT JOIN `user_team` `ut` ON `u`.`uuid` = `ut`.`user_uuid`
    LEFT JOIN `team` `t` ON `t`.`uuid` = `ut`.`team_uuid`
    GROUP BY u.`uuid`
  </sql>
</view>
```

## 配置项

配置项矩阵用于引用 CMDB 配置项数据。当表单或流程中需要选择主机、应用、数据库等配置项对象时，可以通过关联配置项模型并选择模型属性生成矩阵数据。

使用配置项矩阵可以减少重复录入，并保持业务数据与配置管理数据一致。模型数据源可参考配置管理中的[模型管理](../../3.配置管理/系统管理/模型管理.md)。

![矩阵管理_配置项矩阵](images/矩阵管理_配置项矩阵.png)

## 自定义视图

自定义视图矩阵用于引用配置管理中的公共自定义视图。配置时，可以选择已有公共视图，并勾选需要作为矩阵字段的属性。

矩阵数据会随自定义视图的数据动态变化，适合把已经整理好的配置项视图作为选择项或过滤条件使用。自定义视图详情可参考配置管理中的[自定义视图](../../3.配置管理/自定义视图/自定义视图.md)。

![矩阵管理_自定义视图矩阵](images/矩阵管理_自定义视图矩阵.png)
