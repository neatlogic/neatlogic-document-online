# 数据源
数据源管理页面是用来管理非本地的数据库配置，应用于数据仓库，作为数据仓库配置的数据库类型。
![](images/数据源管理.png)

### 配置示例
```
{"password":"xxxxxxxx","driverClassName":"com.mysql.jdbc.Driver","user":"root","url":"jdbc:mysql://192.168.0.1:3306/neatlogic_develop?characterEncoding=UTF-8"}
```
