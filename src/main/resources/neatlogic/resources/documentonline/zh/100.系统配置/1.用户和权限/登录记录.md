# 登录记录

登录记录用于查看系统用户的登录历史。

当管理员需要排查账号是否异常登录、确认用户最后登录时间，或审计用户登录来源时，可以通过登录记录查看登录人、登录时间、登录 IP 和登录方式等信息。

## 阅读路径

- 如果只是查看记录字段，先阅读“功能说明”。
- 如果需要定位某个用户或时间段内的登录行为，阅读“查询功能”。
- 如果用户看不到登录记录页面，阅读“相关权限”。

![](images/登录记录.png)

## 功能说明

功能说明用于了解登录记录中展示了哪些关键信息。

登录记录列表展示以下信息：

- **登录人**：登录用户的账号名称。
- **登录时间**：用户登录系统的时间。
- **登录 IP**：用户登录时的 IP 地址。
- **登录方式**：用户登录的认证方式，如免密登录、密码登录等。

## 查询功能

查询功能用于从大量登录记录中快速定位目标记录。

支持按以下条件筛选登录记录：

1. 按用户名搜索
2. 按登录时间范围筛选

## 相关权限

查看登录记录需要具备用户管理权限。

配置位置：系统配置-[权限管理](权限管理.md)-用户管理权限。
