# 集成与发布入门

集成与发布模块用于管理应用发布所需的流水线、版本、环境配置和发布作业。

模块以应用为核心：应用包含模块，模块关联环境，环境包含一个或多个实例。管理员可以在应用配置中维护发布流水线和环境差异，执行人员可以通过一键发布、超级流水线或定时作业发起发布，并在版本中心管理版本和编译制品。

## 阅读路径

可根据当前要完成的工作选择阅读入口。

- 如果需要完成应用、模块、环境和流水线的基础配置，阅读“应用配置”。
- 如果需要创建发布版本或管理编译制品，阅读“版本中心”。
- 如果需要复用流水线中的常用参数，阅读“预置参数集”。
- 如果需要发起单个应用或模块的发布作业，阅读“一键发布”。
- 如果需要编排并发或分批的批量发布任务，阅读“超级流水线”。
- 如果需要按计划自动发起发布作业，阅读“定时作业”。

## 功能地图

| 功能区域 | 主要作用 | 适用场景 |
|:--|:--|:--|
| [应用配置](配置/应用配置.md) | 配置应用、模块、环境、流水线、执行器、实例、变量和授权 | 首次接入应用，或需要维护不同模块、环境的发布差异 |
| [版本中心](配置/版本中心.md) | 管理版本、封板、编译信息和工程目录制品 | 发布作业需要选择版本，或需要查看、下载和维护编译制品 |
| [预置参数集](配置/预置参数集.md) | 保存和复用流水线工具的常用参数值 | 多条流水线或多个阶段需要复用相同参数组合 |
| [一键发布](作业/一键发布.md) | 发起单个发布作业和批量发布作业 | 需要手动执行一次应用、模块或环境发布 |
| [超级流水线](作业/超级流水线.md) | 配置批量发布模板、通道和子作业 | 需要按通道编排多个应用或模块的批量发布 |
| [定时作业](作业/定时作业.md) | 定时发起普通作业或超级流水线作业 | 需要在固定时间执行发布、构建或批量发布 |

## 入门配置顺序

首次使用集成与发布模块时，建议先完成一条可发布的最小链路：

1. 在配置管理中准备应用系统、应用模块和应用实例数据，并维护应用环境全局属性。
2. 在自动化模块中准备发布流水线需要使用的组合工具、执行器组、账号、资产和工具参数。
3. 在应用配置中选择应用，配置应用层流水线，并关联模块、环境和执行器组。
4. 根据发布差异，在模块层或环境层重定义流水线、执行账号、预置参数、数据库配置、配置文件变量和实例。
5. 在应用配置中为执行人员授予应用的查看配置、执行、环境和场景权限；需要维护版本和制品时，授予版本和制品管理权限。
6. 如果流水线包含构建或部署工具，在版本中心创建可用版本，并确认版本未封板。
7. 通过一键发布选择应用、模块、环境、场景和版本，先发起一条单个发布作业验证配置。
8. 需要批量发布时，创建超级流水线；需要按计划执行时，再配置定时作业。
9. 需要在代码提交后自动触发发布时，在应用配置中维护持续集成，并完成代码仓库 Webhook 配置。

> 注意：应用层流水线是模块层和环境层的基础。模块层或环境层启用重定义后，可以覆盖上一级配置；清空重定义配置后，会恢复继承上一级流水线。

## 常见使用场景

### 首次发布一个应用

管理员先在应用配置中维护应用流水线、模块、环境、执行器和实例，再在版本中心创建发布版本。执行人员获得应用执行权限后，可以在一键发布中选择应用、模块、环境、场景和版本，发起发布作业。

### 为不同环境配置发布差异

应用层用于维护通用流水线。测试、预生产和生产环境存在不同参数、账号、数据库、配置文件或实例时，可以在模块层或环境层重定义对应配置，避免为每个环境重复创建完整流水线。

### 管理版本和编译制品

发布作业执行构建脚本后，版本中心会记录编译次数、BuildNo 和工程目录。需要发布构建类或部署类作业时，选择未封板版本；需要获取制品时，可以在版本、BuildNo 或环境对应的工程目录中查看和下载。

### 批量发布多个应用或模块

对于多个应用或模块需要协同发布的场景，可以创建超级流水线，将子作业模板添加到不同批量通道。同一通道中的作业按顺序执行，不同通道可以同时开始执行。

### 定时执行发布任务

对于固定时间的构建、发布或批量发布任务，可以创建定时作业。普通作业适合固定应用、模块和环境的单次发布；超级流水线作业适合定时发起预设的批量发布任务。

### 通过代码提交触发发布

在应用配置中创建持续集成配置，并在代码仓库中启用 Webhook 回调。满足触发条件的代码提交会触发对应发布作业，适合持续集成或持续交付场景。

## 菜单权限说明

以下权限需在系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权中配置。应用、环境、场景、版本和批量作业还会受到应用数据权限或作业授权控制，实际可见菜单和可执行操作以当前权限配置为准。

| 菜单 | 权限 |
|:--|:--|
| 应用配置 | 应用配置维护权限；自动发布管理权限 |
| 版本中心 | 自动发布管理权限；应用数据权限中的查看配置、版本和制品管理权限 |
| 预置参数集 | 自动发布管理权限 |
| 一键发布 | 发布基础权限；自动发布管理权限；应用执行权限 |
| 超级流水线 | 超级流水线管理权限；批量发布管理权限 |
| 定时作业 | 发布定时管理权限；应用执行权限或超级流水线执行权限 |

> 自动发布管理权限拥有集成与发布模块全部页面的资源和操作权限，不受数据范围限制。

## 阅读建议

如果只想了解模块范围，可以先阅读本文。首次接入应用时，优先阅读应用配置和版本中心；需要实际执行发布时，阅读一键发布；需要批量或定时执行时，继续阅读超级流水线和定时作业。遇到应用、环境、场景或版本无法选择时，先检查应用配置完整性和应用数据权限。
