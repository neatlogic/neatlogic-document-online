# 报表入门

报表模块用于按业务场景配置数据查询、报表展示、定时发送和大屏展示能力。

管理员可以先通过报表模板管理定义数据源、过滤条件和展示内容，再在报表管理中生成具体报表并授权给用户。普通用户获得授权后，可以在报表页面查看和导出报表。

## 功能概览

- 报表：查看已授权的报表，按条件过滤数据，并导出 PDF、Word 或 Excel 文档。
- 报表模板管理：定义报表模板的数据源、过滤条件和内容展示方式。
- 报表管理：基于报表模板创建具体报表，配置展示条件、默认过滤值、显示字段和字段排序。
- 发送计划：按计划将报表发送给指定用户，并查看发送记录。
- 大屏管理：配置可视化大屏，用于实时监控、数据展示和辅助决策。

## 权限

报表模块涉及报表查看、报表配置、模板配置和大屏配置等权限。管理员需要根据人员职责授权，避免普通用户看到或维护不属于自己的报表配置。

![](images/报表权限.png)

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-报表基础权限
- 包含操作：查看已授权报表、按条件过滤报表数据、导出报表
- 配置人员：系统超级管理员

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-报表管理员权限
- 包含操作：新增、编辑、删除报表，配置报表展示条件、默认过滤值、显示字段和字段排序，维护发送计划
- 配置人员：系统超级管理员

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-报表模板管理员权限
- 包含操作：新增、编辑、删除报表模板，配置数据源、过滤条件和内容展示方式
- 配置人员：系统超级管理员

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-报表模板超级管理员权限
- 包含操作：管理全部报表模板及模板授权
- 配置人员：系统超级管理员

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-大屏管理权限
- 包含操作：新增、编辑、删除和预览大屏，维护大屏组件、图层和数据配置
- 配置人员：系统超级管理员

## 配置流程

常见配置流程如下：

1. 在报表模板管理中配置数据源，定义报表可查询的数据和返回字段。
2. 在报表模板管理中配置条件，定义用户查看报表时可使用的过滤项。
3. 在报表模板管理中配置内容，定义报表数据的展示方式。
4. 在报表管理中基于模板创建报表，配置展示条件、默认过滤值和字段展示。
5. 按需要配置发送计划或大屏，将报表数据用于定时通知或可视化展示。
