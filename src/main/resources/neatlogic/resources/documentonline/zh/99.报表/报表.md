# 报表

报表用于查看已授权的报表数据，并支持按条件过滤和导出结果。

普通用户进入报表页面后，只能看到自己有权限访问的报表。点击报表标题，可进入报表查看页面，根据页面提供的过滤条件查询数据，并按需导出为 PDF、Word 或 Excel 文档。

## 权限

**操作权限**
- 配置：系统配置-[用户管理](../100.系统配置/1.用户和权限/用户管理.md)-授权-报表基础权限
- 包含操作：查看已授权报表、按条件过滤报表数据、导出报表
- 配置人员：系统超级管理员

## 查看报表

报表列表只显示当前用户被授权查看的报表。用户可以通过报表标题进入详情页面，查看报表模板和报表管理共同生成的报表内容。

![](images/查看报表.png)

## 条件过滤

报表的过滤条件来自报表模板中的条件配置，也会受到报表管理中展示条件和默认过滤值的影响。

用户可以根据页面展示的条件筛选数据，例如按时间范围、状态、类型或其他业务字段过滤报表内容。

## 导出报表

报表支持导出为 PDF、Word 或 Excel 文档。

导出前建议先确认当前过滤条件，确保导出的数据范围符合当前统计或分析需要。
