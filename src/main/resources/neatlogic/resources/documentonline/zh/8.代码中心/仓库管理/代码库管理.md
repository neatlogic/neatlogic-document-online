# 代码库管理

代码库管理用于维护代码仓库的配置信息，包括仓库地址、访问凭证、同步策略等。通过代码库管理，系统可以自动同步代码仓库信息，支持代码审查、自动化构建等操作。

**相关权限**：代码中心-[仓库管理]-代码库管理权限

![](images/代码库管理_代码库列表.png)

## 添加代码库

点击添加按钮，可新增代码库配置。

![](images/代码库管理_添加代码库.png)

代码库配置包括以下信息：

- **代码库名称**：用于标识代码库，名称不能重复。
- **仓库地址**：代码仓库的Git地址，支持HTTP和SSH协议。
- **访问凭证**：选择已配置的仓库凭证，用于访问代码仓库。
- **同步策略**：配置代码库的自动同步频率和同步范围。
- **说明**：代码库的用途说明。

## 编辑代码库

选择已有代码库进入编辑页面，可修改代码库名称、仓库地址、访问凭证和同步策略。

![](images/代码库管理_编辑代码库.png)

编辑代码库时，系统会验证仓库地址和凭证的有效性，确保修改后的配置能够正常访问代码仓库。

## 删除代码库

对不再使用的代码库，可执行删除操作。删除代码库会清除相关的同步记录和缓存数据。

![](images/代码库管理_删除代码库.png)

## 同步代码库

代码库支持手动同步和自动同步。手动同步可立即获取最新的代码仓库信息，自动同步按照配置的同步策略定期执行。

![](images/代码库管理_同步代码库.png)

同步内容包括：

- 仓库基本信息（分支、标签、提交记录）
- 代码文件列表
- 代码变更记录

## 权限说明

代码库管理页面涉及代码库管理权限：

![](images/代码库管理_权限说明.png)

**代码库管理权限**：拥有该权限的用户可以进入代码库管理页面，维护代码库配置，包括添加、编辑、删除和同步操作。

## 使用建议

1. 建议为重要的代码仓库配置自动同步，保持数据实时更新。
2. 定期检查代码库同步状态，确保同步正常执行。
3. 删除代码库前务必确认不再需要相关数据，避免误删。
4. 代码库命名应清晰明确，方便识别和管理。
