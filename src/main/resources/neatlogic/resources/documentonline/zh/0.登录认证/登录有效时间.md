# 用户登录有效时间
**<font color=red>！！必须确保所有服务器的时间都是正确的</font>**
## 自动登出原因

1. 用户超过有效时间没有点击或滚动鼠标
   
   调整方法：可以通过config.properties 设置
      <table style="width:100%">
   <thead>
      <tr>
         <td>key</td>
         <td>默认值</td>
         <td>单位</td>
         <td>描述</td>
      </tr>
   </thead>
   <tbody>
      <tr>
         <td>user.expiretime</td>
         <td>60</td>
         <td>min</td>
         <td>登录有效时间</td>
      </tr>
   </tbody>
   </table>

2. 同个账号在不同的浏览器重新登录，系统默认会挤退之前在别的浏览器登录这个账号的用户
   
   ```
   可以通过在VM Option增加-DenableConcurrentSession=true 来允许同个账号在不同浏览器登录且不会相互挤退
   ```
