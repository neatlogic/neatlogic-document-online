# 定期强制修改密码
开启后将启用用户密码有效期检查：当用户密码超过有效期时，用户仍可登录成功，但系统将强制跳转至修改密码页面。

## 配置参数
打开页面 系统配置-系统参数 修改保存后立马生效
<table style="width:100%">
   <thead>
      <tr>
         <td>key</td>
         <td>默认值</td>
         <td>描述</td>
      </tr>
   </thead>
   <tbody>
      <tr>
         <td>password.need.expired.check</td>
         <td>0</td>
         <td>是否需要检验用户密码有效期。默认为0，不需要检查</td>
      </tr>
      <tr>
         <td>password.expire.days</td>
         <td>30</td>
         <td>用户密码有效期（天），超过有效期则强制跳转改密码页面</td>
      </tr>

   </table>
