# 告警类型管理

告警类型管理用于区分告警的业务分类和处理方式。不同类型可以关联不同的适配器、事件插件或处理逻辑，让接入后的告警能够按类型展示、收敛和触发后续动作。

## 阅读路径

可根据当前要解决的问题选择阅读入口。

- 如果需要维护告警类型，阅读“告警类型管理”。
- 如果需要配置类型前置数据，先确认告警来源和接入适配器已配置。
- 如果需要在类型事件中触发扩展动作，阅读[事件插件管理](事件插件管理.md)。

## 配置内容

| 配置 | 说明 |
|:--|:--|
| 类型名称 | 用户在告警列表和详情中看到的告警分类 |
| 唯一标识 | 系统识别告警类型的编码 |
| 适配器插件 | 接入或解析该类型告警的插件 |
| 事件插件 | 告警创建、收敛、关闭、屏蔽等事件触发时执行的插件 |
| 是否激活 | 控制该类型是否可继续使用 |

## 使用建议

告警类型应和监控来源、业务分类或处理规则保持一致。类型过多会增加维护成本，类型过少会影响后续筛选、收敛和插件处理。

## 操作权限

告警类型管理权限需在“系统配置 - 用户管理 - 授权”中配置。

| 权限 | 说明 |
|:--|:--|
| 统一告警平台基础权限（ALERT_BASE） | 使用统一告警平台模块 |
| 告警类型管理权限（ALERT_TYPE_MODIFY） | 新增、修改和删除告警类型 |
